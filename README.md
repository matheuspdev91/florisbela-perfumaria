# Florisbela — Landing Page

Landing page premium para a Florisbela Perfumaria.

## Estrutura

- `index.html` — estrutura da página
- `style.css` — identidade visual e responsividade
- `script.js` — interações
- `PALETA.md` — paleta oficial da marca
- `assets/logo-florisbela.png` — logo fornecido pela marca
- `assets/florisbela-hero.mp4` — vídeo principal do Hero
- `assets/florisbela-hero-poster.jpg` — imagem de fallback/poster

## Direção visual

Preto profundo, dourado metálico e marfim, com estética editorial de luxo.
