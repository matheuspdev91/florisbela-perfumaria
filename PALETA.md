# Florisbela — Identidade Visual

## Paleta oficial

A identidade visual da landing page da Florisbela Perfumaria será construída sobre uma combinação de **preto profundo, dourado metálico e marfim**.

| Nome | HEX | Uso |
|---|---|---|
| Preto profundo | `#080604` | Fundo principal |
| Preto elegante | `#14110D` | Seções e superfícies |
| Preto suave | `#211C17` | Cards e áreas de contraste |
| Dourado principal | `#B88A3E` | Logo, títulos, bordas e detalhes |
| Dourado champagne | `#D4A85C` | Destaques e elementos premium |
| Dourado luminoso | `#E8C47A` | Hover, reflexos e pequenos brilhos |
| Off-white / Marfim | `#F4EFE6` | Textos principais |

## Princípios de uso

- O **preto** é a base dominante da interface.
- O **dourado** funciona como cor de destaque e não deve ser aplicado indiscriminadamente.
- Evitar amarelo puro ou dourado excessivamente saturado.
- Gradientes dourados devem ser sutis e usados para criar sensação metálica.
- O marfim deve substituir o branco puro nos textos principais sempre que possível.
- A estética deve transmitir **luxo, elegância, sofisticação e perfume**, sem excesso de efeitos.

```css
:root {
    --black: #080604;

    --black-card: #211C17;

    --gold: #B88A3E;
    --gold-champagne: #D4A85C;
    --gold-light: #E8C47A;

    --ivory: #F4EFE6;

```

## Direção visual

**Palavras-chave:** luxury, editorial, minimalista, sofisticado, cinematográfico.

A referência de materialidade do dourado é metálica: áreas de sombra, bronze e reflexos champagne, em vez de uma cor amarela chapada.
